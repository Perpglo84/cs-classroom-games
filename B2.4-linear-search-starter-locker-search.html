What was your strategy for choosing lockers?

With no order to the names, any locker is as good as any other. The only reliable strategy is to check every locker once, without repeats. Going left to right is the simplest way to guarantee that: this is linear search.

When could you stop?

As soon as you find the target. If the target isn't there, you can only stop after checking every locker.

What is the best case? The worst case?

Best case: 1 check (the first locker). Worst case: all 8 checks (the last locker, or not there at all). With n items the worst case is n comparisons, which is O(n).

Zara isn't in the class list. When do you know?

Only after opening every locker. You can never declare "not found" early in an unsorted list.

Would sorting the names help?

Linear search works on unsorted data, which is its big advantage. If the list were sorted alphabetically, you could use a faster method (binary search). That's coming next.

def linear_search(names, target):
    for i in range(len(names)):
        if names[i] == target:
            return i      # found: stop early
    return -1         # checked everything: not found
