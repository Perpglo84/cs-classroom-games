How many passes does the outer loop make for 8 items?

7. range(n - 1) is range(7), so i takes the values 0 to 6. After 7 passes the one remaining item must already be the smallest.

How many comparisons happen when i = 2?

5. The inner loop is range(n - i - 1) = range(8 - 2 - 1) = range(5).

How many comparisons happen in total?

7 + 6 + 5 + 4 + 3 + 2 + 1 = 28. The number of swaps depends on how unsorted the list was. This list needs 16 swaps.

bubble_sort has no return. Why is numbers sorted afterwards?

A list is mutable. arr and numbers refer to the same list, so changing arr inside the function changes numbers. This is called sorting in place.

What would change if line 7 used < instead of >?

The list would be sorted into descending order: the smallest values would bubble to the end.

The last passes swap nothing. How could we stop early?

Set swapped = False at the start of each pass, set it to True inside the if, and break out of the outer loop if a pass ends with no swaps. If nothing moved, the list is already sorted.
